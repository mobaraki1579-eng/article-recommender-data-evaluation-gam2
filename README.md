# آماده‌سازی داده و ارزیابی — سیستم پیشنهاددهنده مقاله

این مخزن بخش «آماده‌سازی داده و ارزیابی» از پروژه آزمایشگاه هوش مصنوعی را نگه‌داری می‌کند. هدف این بخش، بررسی مجموعه‌داده مقالات SID، پاک‌سازی اولیه، تحلیل توصیفی، آماده‌سازی فایل‌های ورودی برای پیاده‌سازی سیستم پیشنهاددهنده و تعریف چارچوب ارزیابی است.

> **وضعیت:** آماده‌سازی و تحلیل اولیه داده‌ها در نوت‌بوک انجام شده است. ارزیابی نهایی کیفیت پیشنهادها هنوز انجام نشده، چون به خروجی سیستم پیشنهاددهنده و تعیین مرتبط‌بودن نتایج نیاز دارد.

## مجموعه‌داده

- نام: `MCINext/sid-clustering`
- منبع: مقالات علمی گردآوری‌شده از پایگاه SID
- زبان: فارسی
- تعداد نمونه‌ها: ۱۲٬۴۴۷
- آموزش: ۸٬۷۱۲ نمونه
- آزمون: ۳٬۷۳۵ نمونه
- ستون‌های اصلی: `sentences` و `labels`
- متن `sentences` عنوان و چکیده را با جداکننده دو خط جدید (`\n\n`) کنار هم قرار می‌دهد.
- برچسب‌ها شامل ۸ دسته عددی هستند؛ در این پروژه تا زمان تأیید مستندات، برای آن‌ها نام موضوعی حدس زده نمی‌شود.

صفحه رسمی مجموعه‌داده: https://huggingface.co/datasets/MCINext/sid-clustering

## کارهای انجام‌شده

1. بارگذاری فایل‌های Parquet آموزش و آزمون.
2. بررسی نمونه‌های داده و ساختار ستون‌ها.
3. بررسی مقادیر خالی و ردیف‌ها/متن‌های تکراری در هر split.
4. شمارش نمونه‌ها در دسته‌های عددی.
5. محاسبه آمار طول متن‌ها.
6. رسم نمودار توزیع تعداد مقاله‌ها در دسته‌ها.
7. جداکردن عنوان و چکیده از متن اصلی.
8. حذف ردیف‌های فاقد متن یا برچسب و متن‌های خالی.
9. بررسی وجود متن مشترک بین آموزش و آزمون و نمایش برچسب هر مورد در هر دو split.
10. تعریف ۱۵ پرس‌وجوی فارسی نمونه برای آزمایش سیستم.
11. آماده‌سازی قالب ثبت نتایج و تابع `Precision@5`.

## مواردی که هنوز تکمیل نشده‌اند

- بررسی و تصمیم‌گیری مستند درباره مقاله‌های مشترک آموزش و آزمون؛ آن‌ها نباید بدون بررسی حذف شوند.
- تولید پیشنهادهای واقعی توسط بخش کدنویسی.
- تعیین مرتبط/نامرتبط بودن هر نتیجه برای هر پرس‌وجو.
- محاسبه و گزارش نهایی `Precision@5` و میانگین آن.

تابع `Precision@5` در نوت‌بوک صرفاً چارچوب محاسبه است. تا زمانی که نتایج واقعی و برچسب ارتباط آن‌ها وارد نشوند، عددی به‌عنوان عملکرد سیستم گزارش نمی‌شود.

## راه‌اندازی

### ۱. دریافت مخزن

```bash
git clone <YOUR_REPOSITORY_URL>
cd article-recommender-data-evaluation
```

### ۲. ساخت محیط و نصب وابستگی‌ها

```bash
python -m venv .venv
```

فعال‌سازی در ویندوز:

```bash
.venv\Scripts\activate
```

فعال‌سازی در macOS/Linux:

```bash
source .venv/bin/activate
```

نصب کتابخانه‌ها:

```bash
pip install -r requirements.txt
```

### ۳. قراردادن داده‌ها

فایل‌های Parquet مجموعه‌داده را از صفحه رسمی دریافت کنید و در پوشه `dataset/` قرار دهید. نام فایل‌ها باید شامل `train` و `test` باشد تا نوت‌بوک بتواند splitها را تشخیص دهد.

ساختار مورد انتظار:

```text
dataset/
├── <train-parquet-file>.parquet
├── <test-parquet-file>.parquet
└── processed/
```

### ۴. اجرای نوت‌بوک

از ریشه مخزن اجرا کنید:

```bash
jupyter notebook
```

سپس فایل `notebooks/data_analysis.ipynb` را باز و سلول‌ها را به ترتیب اجرا کنید.

فایل‌های پاک‌سازی‌شده و پرس‌وجوها در `dataset/processed/` ذخیره می‌شوند:
- `train_clean.csv`
- `test_clean.csv`
- `evaluation_queries.csv`

## تحویل به مسئول کدنویسی

پس از اجرای موفق نوت‌بوک، سه فایل خروجی داخل `dataset/processed/` را در اختیار مسئول کدنویسی قرار دهید. این فایل‌ها برای شروع پیاده‌سازی و آزمایش سیستم پیشنهاددهنده آماده شده‌اند.

## معیار ارزیابی

`Precision@5` نسبت نتایج مرتبط در پنج پیشنهاد اول به عدد ۵ است:

```text
Precision@5 = (تعداد نتایج مرتبط در پنج رتبه اول) / 5
```

برای محاسبه معتبر، باید نتایج واقعی سیستم و قضاوت مرتبط/نامرتبط بودن هر نتیجه ثبت شود. اگر کمتر از پنج نتیجه برگردانده شود، جایگاه‌های خالی مرتبط محسوب نمی‌شوند.
