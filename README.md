# سیستم پیشنهاددهنده مقاله

این پروژه به‌صورت گروهی و در چهار بخش انجام می‌شود: طراحی، داده و ارزیابی، کدنویسی و مستندسازی.

## مسئولیت من: داده و ارزیابی

من مسئول آماده‌سازی و بررسی دیتاست بودم. کارهایی که در این بخش انجام دادم:

- بارگذاری داده‌های آموزش و آزمون
- بررسی ساختار داده‌ها و ستون‌ها
- بررسی داده‌های خالی و موارد تکراری
- بررسی تعداد مقاله‌ها در دسته‌های مختلف
- بررسی طول متن مقاله‌ها
- جدا کردن عنوان و چکیده از متن هر مقاله
- آماده‌سازی نسخه‌های پاک‌سازی‌شده از داده‌ها
- تعریف چند پرس‌وجوی نمونه برای آزمایش سیستم پیشنهاددهنده
- آماده کردن کد اولیه برای محاسبه معیار `Precision@5`

تمام این مراحل در نوت‌بوک `notebooks/data_analysis.ipynb` قرار دارد.

بخش ارزیابی نهایی، یعنی بررسی کیفیت مقاله‌های پیشنهادی و محاسبه نتیجه واقعی `Precision@5`، بعد از آماده شدن سیستم پیشنهاددهنده و دریافت خروجی آن انجام می‌شود.
